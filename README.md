# My Portfolio - Built with React & TypeScript

This is my personal portfolio, designed as a technical playground to learn modern web technologies.

## Tech Stack
- **Frontend**: React (Vite), TypeScript
- **Database**: Supabase (Hybrid JSON/Database architecture)
- **Deployment**: Vercel with automated CI/CD
- **Routing**: React Router with custom Vercel rewrites

## Key Features
- **Type Safety**: Fully built with TypeScript for robust code.
- **Data-Driven**: Projects and timeline data managed via Supabase.
- **Responsive**: Mobile-compatible design.
- **Automated**: Integrated CI/CD pipeline.
